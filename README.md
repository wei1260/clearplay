# 澄映 · Clearplay

Windows 桌面视频播放器，支持百度网盘、夸克网盘和本地视频。使用 Electron 和原生 HTML / CSS / JavaScript，无需启动额外的后台服务。

安卓手机版：`release/Clearplay-0.1.10-android.apk`，支持 Android 8.0 及以上。已增加百度/夸克视频的下载按钮，支持保存到手机“下载/澄映”目录；已安装到 REDMI K80 并完成真实按钮下载校验。使用方法见 [Android 说明](android/README.md)。

## 直接运行

Windows 新包为 `release/Clearplay-0.1.5-portable.exe`，已移除百度网页原文件的普通取链回退；百度原画起播仍有未通过记录。下载与打包结果见 `test-results/android/throughput/BAIDU-DOWNLOAD-RESULTS-2026-11-10.md`。升级沿用本机账号会话和播放记录。

打开后可以先点“播放 1080P 示例”体验播放。示例是本项目生成的 1920 × 1080 动画，不是网盘文件。可以通过“打开本地视频”选择一个或多个视频。

## 连接网盘

### 百度网盘

默认方式不需要 AppKey / SecretKey：

1. 选择“百度网盘”，点击连接，再点击“打开百度官网登录窗口”。
2. 在百度官网使用扫码或账号方式登录。
3. 返回播放器点击“完成登录，连接百度”。验证目录后即可选择视频。

已有应用授权的用户，可在“管理网盘连接”里点击“改用官网直接登录，优先转码播放”。网页连接验证成功前，原有应用授权和播放记录继续保留。

如果使用应用授权，展开“高级：应用密钥授权”，在[百度网盘开放平台](https://pan.baidu.com/union)申请接入并完成认证，进入控制台创建应用，在应用详情复制 AppKey 和 SecretKey。填入播放器、生成授权码，再在百度官方页面完成授权。密钥是开发者应用的凭证，并非账号密码。

高级方式使用百度设备码 OAuth，申请 `basic,netdisk` 权限；访问令牌过期后尝试通过 refresh token 续期。AppKey、SecretKey 和令牌由 Electron `safeStorage` 加密。默认网页登录使用独立的本机会话，不读取其他浏览器的登录信息。已有 OAuth 授权升级时保持可用。

### 夸克网盘

1. 选择“夸克网盘”，点击连接。
2. 点击“打开夸克官网登录窗口”，在独立的夸克官网窗口完成登录。
3. 回到播放器点击“完成登录，连接夸克”。目录验证成功后才会显示已连接。

夸克使用独立的 Chromium 登录会话和网页接口，不要求手动复制 Cookie。会话保存在应用自己的用户目录中，不读取浏览器、其他客户端或其他应用的登录信息。网页接口可能变化，登录失效后需要重新登录。

两个登录窗口均显示加载状态。网络或证书问题、页面加载超时会显示具体错误和“重新加载”，页面实际显示内容后才展示官网区域，不再以空白窗口表示加载失败。上方“刷新页面”和“返回播放器”始终可用。

## 播放能力

- 0.5、0.75、1、1.25、1.5、1.75、2、2.5、3、4 倍速；倍速和音量在下次启动时保留。
- 百度应用授权播放接口返回的原文件；百度网页登录和夸克尝试获取原文件及转码资源，清晰度列表只显示成功返回的画质。存在转码资源时优先用 720P 或其他可用转码流起播，可手动选择原画。
- 百度网页登录原画统一使用视频专用取链（`web=5,origin=dlna`）与 `netdisk` 请求头，已移除普通原文件取链回退。手机两个文件的完整下载和续传 SHA-256 校验通过；具体结果见 `test-results/android/throughput/BAIDU-DOWNLOAD-RESULTS-2026-11-10.md`。接口策略可能变化。
- 网盘返回 133 视频准备响应时，按其等待时间显示倒计时，等待结束后携带本次返回的准备凭据重新取流。
- 百度网页转码资源同时尝试取得当前文件的独立音频流，通过 HLS 音频组与画面统一播放，修复部分转码流只有画面、没有音频数据的问题。倍速、暂停和拖动由同一个播放器同步处理；独立音频接口不可用时沿用视频内嵌音轨。
- 上述处理位于所有目录共用的播放流程中；每条视频独立取得地址和准备凭据，切换目录或选择新视频时不会复用上一条视频的播放链接。
- 原文件采用流式读取，支持 HTTP Range；HLS 播放列表、分片和密钥由主进程中转。
- 百度原画的大范围读取在主进程按 256 KB 分段取回，并复用已解析的 CDN 地址，向播放器返回连续的媒体流。读取中断会报告 HTTP 状态或传输错误。
- 切换清晰度保留当前进度、倍速和暂停状态。
- 文件夹浏览、分页、当前已加载目录搜索、同目录播放队列、可选自动下一集。
- 最近 100 条播放记录、本地文件列表、断点续播。进度每约 5 秒及暂停、切换视频时保存，接近片尾则下次从头播放。
- 空格播放 / 暂停；左右方向键跳转 10 秒；上下方向键调节音量；M 静音；F 全屏。输入框和选择控件获得焦点时保留原本的键盘行为。

分辨率取决于源文件和网盘实际返回的资源，不会将低清文件变成高清。网盘带宽、转码状态和账号权益仍适用。Electron 的媒体解码依赖 Chromium 与本机系统，不保证所有 MKV、AVI、HEVC、杜比或其他特殊编码均可播放；遇到不支持的编码，可以尝试网盘返回的其他转码画质。

原画 MP4 可能将较大的索引放在文件尾部，首播仍需要先读取该索引，不能保证秒开。倍速越高，对持续带宽的要求也越高；传输带宽不足时可尝试较低画质或降低倍速。

## 数据存储

当前 Windows 成品默认位于 `%APPDATA%/澄映播放器/`，实际以 Electron 的 `app.getPath('userData')` 为准：

- `baidu-auth.bin`：加密的百度应用信息及授权。
- `Partitions/clearplay-quark/`：独立夸克登录会话。
- `Partitions/clearplay-baidu/`：独立百度网页登录会话。
- `library.json`：播放记录和用户选择过的本地视频路径。

播放器界面仅接触随机生成的本地媒体地址，不接收网盘令牌、Cookie 或带签名的远程播放链接。主窗口启用进程沙箱、上下文隔离和内容安全策略。只有本机主窗口允许请求全屏权限。

“断开连接”清除本机该网盘的授权或会话，保留观看记录；百度开放平台中的授权记录可在百度账号侧另行管理。

## 本地开发和打包

需要 Node.js 22.12 或以上版本。仓库锁定了依赖版本。

```powershell
npm.cmd ci
npm.cmd start
npm.cmd test
npm.cmd run test:desktop
npm.cmd run test:login
npm.cmd run build
```

`npm.cmd run build` 生成 Windows x64 便携版和 `win-unpacked` 目录。开发工具和测试不包含在成品中。

示例视频已随源码提供。重新生成时，运行 `npm.cmd run sample`；需要 Playwright Chromium 及 FFmpeg。脚本会寻找本机 Playwright 缓存，也可以通过 `FFMPEG_PATH` 指定 FFmpeg 可执行文件。

- `npm.cmd run test:desktop`：9 组桌面检查通过。1080P 示例和本地视频实际解码播放，验证倍速计时、拖动进度、全屏、多文件队列、断点续播、重启持久化及取流失败提示。
- 桌面测试中的夸克目录和清晰度使用适配器模拟数据，媒体仍采用实际视频解码。接口单元测试使用模拟 HTTP 响应。
- `npm.cmd run test:login`：百度和夸克各验证请求失败时显示错误、恢复网络后重试并实际显示官网登录内容；不使用真实账号登录。
- 真实账号验证原画请求头：同一视频链接用浏览器 User-Agent 返回 403，使用 `pan.baidu.com` 后返回 206 并读到视频数据。
- 真实百度网页登录后，跨两个目录抽测三条视频：都取得原画、720P、480P，720P 视频分片均返回 206；需要平台等待的一条按要求等待 8 秒后取得转码流，其余两条约 1 秒取得资源。
- 0.1.2 成品真实视频：含平台准备的总起播约 11.4 秒；720P、3 倍速连续测量 20 秒，视频进度前进约 60 秒，没有重新缓冲、媒体错误或切换资源；另一次 2 倍速测量 8 秒前进约 16 秒。
- 0.1.3 音频修复：同一真实视频在旧版 720P 下音频解码为 0，采样分片只有视频包；绑定独立音轨后识别到 1 条音轨，音频解码持续增加，PCM 均方根约 0.048、峰值约 0.276，用户同时确认能听到声音。原有无声示例的解码检查不能作为音频验收依据。
- 已知限制：该样本的 720P 在远距离起播至约 5 分钟处出现等待音轨、停在缓冲状态的情况；本版本尚未解决。恢复当前视频声音不代表所有跳转位置均已通过验证。
- 原画 MP4 仍可能有较大的尾部索引（已遇到约 7.7 MB 的实例），不能保证原画首次秒开或持续带宽足够。默认采用实际可用转码画质。
- **未对所有视频逐条验收；夸克真实账号的视频播放尚未验收。** 自动化检查和抽测结果不代表所有格式、网络与账号权益下均可无卡顿播放。

桌面测试报告和截图在 `test-results/` 中，测试采用临时用户目录，不会使用或更改日常账号会话。
